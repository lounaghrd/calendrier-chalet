# Calendrier St Marcel

Le calendrier partagé du chalet de St Marcel : réserver un séjour, voir qui vient et combien de places restent (14 couchages au maximum).

- Site : https://lounaghrd.github.io/calendrier-chalet/
- `index.html` : l'application
- `firestore.rules` : règles de la base de réservations (Firebase)
